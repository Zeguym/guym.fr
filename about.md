Je suis **Guym**, développeur .NET depuis une vingtaine d'années. J'ai connu le framework depuis ses premières versions jusqu'au .NET moderne, multiplateforme et open source, et j'écris ici ce que j'aurais aimé trouver, en français, au moment de résoudre les mêmes problèmes.

## Ce que vous trouverez sur ce blog

Des articles techniques, illustrés par du code C# complet et exécutable, autour de :

- **les bases de .NET et de C#** : pile et tas, égalité et identité, records, `async`/`await`, LINQ, `Span<T>` et `Memory<T>`, Garbage Collector ;
- **l'architecture logicielle** : principes SOLID, Clean Architecture, CQRS, pattern Outbox, injection de dépendances ;
- **l'accès aux données** avec Entity Framework Core et SQL Server ;
- **les systèmes distribués** : gRPC, Dapr, .NET Aspire, OpenTelemetry, Polly ;
- **la qualité** : tests avec xUnit v3, NSubstitute et Testcontainers, tests d'architecture, BenchmarkDotNet ;
- **l'outillage** : Git, GitVersion, Husky, outils `dotnet`, source generators et Roslyn.

Chaque article se lit de manière autonome : pas besoin d'avoir lu les précédents pour suivre.
